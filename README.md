# TF Contacts

সম্পূর্ণ অফলাইন কন্টাক্ট ও ডায়ালার অ্যাপ (Android)।

- ফোনের সব কন্টাক্ট (ফোন, সিম, Google) এক জায়গায়
- ডুপ্লিকেট নিজে থেকে খুঁজে এক ক্লিকে মার্জ
- নাম, নম্বর, ইমেইল, ঠিকানা, নোট — যেকোনো কিছু লিখে খোঁজা
- সুন্দর ডায়াল প্যাড, ডিফল্ট ফোন অ্যাপ হিসেবে ব্যবহার করা যায় (নিজস্ব কল স্ক্রিন)
- প্রতিটি কন্টাক্টে ছবি (ইচ্ছা হলে)
- সিম ↔ ফোন কপি / সরানো
- .vcf এক্সপোর্ট / ইমপোর্ট, মার্জ বা মোছার আগে নিজে থেকে ব্যাকআপ
- ইন্টারনেট পারমিশন নেই

**ডাউনলোড:** Releases পেজে `TF-Contacts.apk`।
